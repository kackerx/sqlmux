## F2.1 单元格编辑与待提交标记 · 状态：draft

- **依赖**：M1
- **涉及**：`internal/app`（DataTab.Edits）、`internal/ui`（grid、单元格输入框）

**内容**
- **行标识列**（§10.1）：依次取主键、所有列都不可空的唯一索引；两者都没有的表只读，用 toast 说明原因。
- **进入编辑**：`↵`、`i`、双击，或者在 NORMAL 下粘贴。进入编辑后是 INSERT 模式，内容全选。
- **提交修改**：`esc`、`↵`、点击别处，都会提交修改并退出编辑。
- **修改记录**：
  - `Edits` 保存修改后的值，值有三种：文本、NULL、DEFAULT；
  - 改回原值时，自动取消修改标记；
  - 已修改的单元格按 §7.6 显示；
  - 保存按钮显示修改的数量（Q-05）。
- **禁止编辑**：只读 session 中不能进入编辑。

**验收**
- [ ] e2e：修改单元格后，出现修改样式（`warn` 色、点状下划线、`edited_bg`）；改回原值后，样式消失；保存按钮上的计数随之更新。
- [ ] 在无主键的表上尝试编辑时，出现 toast，并且无法进入编辑；只有唯一索引的表可以编辑。

## F2.2 保存与刷新 · 状态：draft

- **依赖**：F2.1
- **涉及**：`internal/db`（UPDATE 生成与执行）、`internal/app`

**内容**
- **生成 UPDATE**（§10.3）：
  - 行标识列有多列时，逐列比较；
  - 旧值比较用 `IS NOT DISTINCT FROM`；
  - DEFAULT 直接写成关键字。
- **执行**：
  - 所有 UPDATE 放在一个事务里，每条必须恰好影响 1 行；
  - 否则整体回滚，并在出问题的行上给出提示；
  - 成功后重新加载当前页。
- **触发方式**：`C-s` 或 `:w`；保存结果按 Q-06 显示在查询条右侧。
- **刷新**：`R` 直接丢弃所有修改。

**验收**
- [ ] 集成测试：
  - 单列主键、复合主键、唯一索引三种情况下，生成的 UPDATE 都正确；
  - 写入 NULL、DEFAULT 正确；
  - 从加载到保存之间，另一条连接修改了同一行时，整体回滚，并标出出问题的行。
- [ ] e2e：保存后，查询条显示「saved N rows」，数据已重新加载；`R` 之后，所有修改标记都消失。

## F2.3 单元格选项浮层 · 状态：draft

- **依赖**：F2.1
- **涉及**：`internal/ui`（选项浮层、时间分段）、`internal/app`

**内容**

实现 §10.2 的全部选项：

- NULL、DEFAULT、恢复原值；
- 布尔值（MySQL 写入 1 / 0 的部分在 M5 做）；
- 枚举值，随输入模糊过滤；
- 时间分段：`Tab` / `S-Tab` 切换分段，`↑` / `↓` 增减；「现在」选项；文字与分段双向同步；日期按当月天数限制。
- 键盘与鼠标都能操作。
- 注册「Set NULL」「Set DEFAULT」两个 Action（命令面板在 M4 实现）。

**验收**
- [ ] e2e：
  - timestamptz 列出现分段；在月份上按 `↑` 时，文字同步变化；
  - 1 月 31 日切到 2 月时，日期被限制为 28 或 29；
  - 只有可空列显示 NULL 选项，只有有默认值的列显示 DEFAULT 选项；
  - 枚举选项随输入过滤；点击任一选项后立即生效。
