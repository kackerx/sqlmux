## F4.1 面板框架 · 状态：draft

- **依赖**：M1
- **涉及**：`internal/ui`（palette、遮罩）、`internal/app`

**内容**
- **打开与关闭**：`C-p` 打开，esc 关闭。
- **遮罩**：打开时背景变暗，做法见 §7.5。
- **范围**：
  - 用范围标签切换，`Tab` / `S-Tab` 在标签间循环；
  - 也可以用前缀限定范围：`>` 命令、`@` 表、`$` 会话、`%` 窗口、`;` SQL。
- **匹配**：fzf 算法，支持扩展语法；输入为空时按最近使用排序（持久化）。
- **鼠标**：悬停即移动选中项，点击即执行。
- **显示**：
  - 底栏说明按回车会做什么；
  - 条目右侧显示键位（通过 Hint 获取）或开关状态。

**验收**
- [ ] e2e：
  - 输入 `>split` 能找到分割命令，并显示其键位；
  - 输入 `@t_ord` 能找到表；
  - `Tab` 在范围标签间循环；
  - 悬停时选中项跟随移动，点击后执行；
  - 输入为空时，按最近使用排序。

## F4.2 条目执行与 DDL 预览 · 状态：draft

- **依赖**：F4.1
- **涉及**：`internal/app`、`internal/db`（DDL）

**内容**
- **执行各类条目**（K-04）：
  - session：attach；
  - window：切换；
  - pane：聚焦；
  - 表：在当前 pane 打开，`C-t` 在新 tab 打开；
  - 命令：执行；开关类命令只切换状态，不关闭面板。
- **DDL 预览**（K-05）：
  - 选中项在表上停留 150ms 后才获取 DDL，获取结果会缓存；
  - 窗口高度不够时，先压缩预览区；列表至少保留 3 行。

**验收**
- [ ] e2e：
  - 选中一张表并停留片刻后，出现 DDL 预览；
  - 按 `C-t` 在新 tab 中打开表；
  - 执行开关类命令后，ON / OFF 状态切换，面板不关闭；
  - 窗口较小时，预览区被压缩，列表仍至少有 3 行。

## F4.3 快速 SQL · 状态：draft

- **依赖**：F4.1、F3.3、F3.5
- **涉及**：`internal/app`（快速 SQL）、`internal/db`（只读事务）

**内容**

§12 中快速 SQL 的全部内容：

- **进入**：输入 `;` 进入 SQL 模式。
- **执行**：
  - 在 Meta 连接上开只读事务执行，并自动加上 `LIMIT 101`；
  - 写语句不执行，显示黄色提示，并提示可用 `C-e` 转到 console；
  - 执行出错时，显示红色提示；
  - 输入内容与上次执行的不同时，提示「已修改，↵ 重新执行」。
- **历史**：保留最近 50 条。
- **结果的后续操作**：
  - `C-t`：把结果作为固定 tab 放进结果区；
  - `C-y`：复制为 CSV（OSC 52）；
  - `C-e`：在 console 中打开这条 SQL。

**验收**
- [ ] 集成测试：
  - 写语句不会被执行；
  - `select` 最多返回 100 行，超出时显示 `100+`；
  - 在只读事务中，调用会写数据的函数时报错。
- [ ] e2e：从进入 SQL 模式、执行、查看结果，到使用 `C-t`、`C-y`、`C-e`，整个流程都正确。
