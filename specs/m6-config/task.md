## F6.4 界面多语言 · 状态：draft

- **依赖**：F6.1（键位文字的审计先做完，文案和键位文字分得开）
- **涉及**：所有画界面文字的包（`internal/app`、`internal/ui`）、`internal/config`

**内容**（§14「界面语言」）
- `config.toml` 加 `language = "zh" | "en"`，默认 `zh`，写错启动报错；
- 所有界面文案走一处翻译，中文原文作 key，`en` 表为「中文 → 英文」，找不到显示原文；带参数的文案用占位符；
- Action 的标题跟着语言，命令面板按当前语言的标题搜索，action id 照旧能搜；
- 数据库返回的错误原文、键位文字不翻译；
- 放在哪个包、翻译函数叫什么，开工时由 worker 提议。

**验收**
- [ ] 单测：没有漏掉没走翻译的中文字面量；`en` 表覆盖全部文案。
- [ ] 设 `language = "en"` 后启动，toast、确认框、查询条、结果区、面板、引导页、日志都是英文；golden 各加一张 `en` 的。
- [ ] `language` 写错时启动报错。
