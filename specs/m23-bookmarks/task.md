## F23.2 `SPC 1`–`SPC 9`、顺序、分组、改名 · 状态：todo

- **依赖**：F23.1
- **涉及**：`internal/app`（`bookmark.jump` / `rename` / `group` / `up` / `down`、树的分割线、which-key 列表）、`internal/keymap`

**开发**（§7.10.3、§7.10.4 的分组和右键菜单、§7.10.10）
- [ ] a. `bookmark.jump N`（默认 `<Leader>1`–`<Leader>9`）：打开第 N 个；没有时 toast。先确认按了 leader 之后数字不当次数（`keymap/resolve.go`）。
- [ ] b. 顺序和编号（§7.10.3）：分组的排序规则和连接分组用同一个函数；`bookmark.up` / `bookmark.down` 只在自己那一段里动；`bookmark.group`（状态栏单行输入、带已有组名的补全，同连接表单的 group 字段）；`bookmark.rename`（同 `window.rename`，空 = 去掉别名）。
- [ ] c. 树里分组的分割线（同连接分组的画法，不是节点、`j` / `k` 跳过）；书签行的右键菜单（打开、改名…、移到分组…、上移、下移、移出书签）。

**验收**
- [ ] 单测：编号随上移 / 下移 / 分组 / 删除重排；到头不动；移到空组名 = 移出分组；`bookmark.jump` 有 / 没有第 N 个；which-key 的合并（`1-9` 一项；不连续或 Action 不同的不合并）；mutation。
- [ ] golden：有两个分组的书签区（`#a-main` 带分割线的那张）；which-key（`#a-whichkey`）。
- [ ] e2e：加 10 个书签，`SPC 3` 打开第三个、目标已开着就切过去、第 10 个没有编号；移到分组后分割线出现、编号按画出来的顺序；`SPC` 停住时 `1-9` 只占一项。
